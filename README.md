# Hi, I'm knzbr

Agile coach by day, OSS developer when the itch needs scratching.

I build small, focused tools for true agile teams - tools that solve the kinds of problems I run into in real-world situations.

Currently maintaining:

- [@techspikes/spike-kit-dev](https://github.com/techspikes/spike-kit-dev) - Specification and tools for agile teams to quickly sketch disposable data stores for user stories
- [@techspikes/fastify-mock-fallback](https://github.com/techspikes/fastify-mock-fallback) - Fastify plugin that registers fallback mock routes from an OpenAPI 3.x specification
- [@techspikes/fastify-kysely](https://github.com/techspikes/fastify-kysely) - Minimal Fastify plugin for Kysely with full type inference
